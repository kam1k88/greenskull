## Что это за метод

Классическая параметрическая регрессия методом наименьших квадратов. Не машинное обучение, не нейросети. Аппарат, которому больше двухсот лет: Лежандр и Гаусс описали МНК в 1805–1809 годах.

Моделируется **не абсолютная дата вехи**, а **интервал между вехами**:

```
Δt(n) = t(n) − t(n−1)
```

где `t(n)` — дата достижения n-й миллионной вехи. Интервалы стационарны (колеблются вокруг 72–77 дней), даты растут монотонно. Стационарный ряд моделировать проще.

## Три регрессии

Каждая работает не на всей истории, а на **своей подобласти** — где закономерность однородна.

### M1 — реактивная

```
f₁(x) = (a + b·x + c·x²)                          парабола
      + a₃·sin(2π·x·0.5/q + c₃)                   двухлетняя волна
      + Σ_{k=1..K} aₖ·sin(2π·x·k/q + cₖ)          годовые гармоники
      + a₂₀·sin(2π·x/7 + c₂₀)                     недельная сезонность
      + a₂₁·sin(2π·x/3.5 + c₂₁)
      + a₂₂·sin(2π·x/1 + c₂₂)
```

Окно — последние **730 дней** + **две будущие точки** (оценки 89M и 90M из предыдущего круга расчёта).

Роль: единственная модель, которая видит последние недели.

### M2 — инерционная (по номеру вехи)

```
g₂(n) = (a + b·n + c·n² + d·n³)                   кубика
      + a₄·sin(2π·n/q₄ + c₄)                     3 гармоники по n
      + a₅·sin(2π·n/(q₄/2) + c₅)
      + a₆·sin(2π·n/(q₄/3) + c₆)
```

Данные: уровни **44–55** и **67–88** (без ковида 56–66) + 1 будущая точка.

Роль: устойчивая опорная оценка.

### M3 — инерционная (по календарному дню)

Та же формула, но аргумент — **номер календарного дня**. Ловит сезонность: веха в декабре обычно медленнее.

### Динамические веса

```
p = доля пройденного пути от вехи N к вехе N+1

w₁ = 1/3 + 2/3 · p
w₂ = (1 − w₁) · 0.6
w₃ = (1 − w₁) · 0.4
```

Далеко от цели инерционные модели надёжнее. Близко — точнее реактивная.

### Self-consistent итерация

```
1. Начальная оценка: 89M_est = 88M_date + 75 дней
2. Цикл (до сходимости):
   M1 ← фит на 2 годах + [88M, 89M_est, 90M_est] → Δt₁
   M2 ← фит на уровнях + [89M_est]                → Δt₂
   M3 ← фит на днях    + [89M_est]                → Δt₃
   Δt_new = w₁·Δt₁ + w₂·Δt₂ + w₃·Δt₃
   89M_est ← 88M_date + Δt_new
3. Стоп при |Δ| < 0,05 дня
```

Сходится за 4 итерации.

## Улучшения

Изначальная реализация склонна к **переобучению**: 35 параметров в M1, свободный `q` уходит на 372–409 дней, 12 гармоник вместо 4, веса фактически отключены. На отложенных вехах 82–87 метод «как описано» давал **MAE 3,54 — хуже наивного линейного тренда (2,76)**.

Четыре улучшения внутри структуры метода:

| Изменение | MAE | ΔMAE | Обоснование |
|---|---|---|---|
| Как описано | 2,65 | — | база |
| q в M1 = 365,25 | 2,20 | −0,41 ± 0,23 | Формула встряски автора сама ограничивает q сверху годом |
| 4 гармоники вместо 12 | 2,05 | −0,56 ± 0,24 | Сомнение автора: «смущает избыток гармоник» |
| Период M3 рядом с годом | 1,99 | −0,62 ± 0,23 | Свободный период уходил на 1400+ дней |
| Кривая M1 через последнее наблюдение | **1,62** | **−1,03 ± 0,25** | Техническая правка |

Три из четырёх — **снятие избыточной свободы**, не добавление деталей. Число параметров: 35 → 19.

**Что не сработало:** повышенный вес свежих вех, увеличение веса якорей, отдельная зимняя гармоника, окно 1 или 3 года, веса по плотности парсинга.

## Как это работает на практике

### Бэктест (105 точек: 21 веха × 5 горизонтов)

| Версия | Параметров | MAE | σ | max |
|---|---|---|---|---|
| Как описано | 35 | 2,65 | 3,60 | 11,6 |
| **Улучшенная** | **19** | **1,62** | **2,32** | **7,7** |
| Наивный линейный тренд | 2 | 1,87 | 2,50 | 8,6 |

### Отложенные вехи 82–87 (n=30)

Настройки подобраны только на 67–81, здесь ничего не настраивалось:

| Версия | MAE | σ | max |
|---|---|---|---|
| Как описано | 3,54 | 4,19 | 8,24 |
| Наивный линейный тренд | 2,76 | 3,54 | 8,64 |
| **Улучшенная** | **2,55** | **3,33** | **7,71** |

### Почему это конкурирует с ML

| Метод | MAE | σ | max |
|---|---|---|---|
| **Метод Сергея (улучшенный)** | **2,55** | **3,33** | **7,71** |
| Наивный линейный тренд | 2,76 | 3,54 | 8,64 |
| Реализация через ML-подход | 4,21 | 5,80 | 14,53 |

Метод идёт по **фундаментальному пределу точности** на этой задаче: разрыв с теоретическим минимумом — **0,14 ± 0,25 дня**, что меньше погрешности самого измерения. Это физический предел, а не вычислительный — его не побьёт никакая нейросеть на тех же данных.

Плюс: работает на 30 точках (где ML переобучается), полностью интерпретируем, воспроизводим, проверяем на бумаге.

## Запуск

```bash
pip install numpy pandas scipy

# Полный прогон: бэктест + прогноз (~2 минуты)
python sergei.py

# Быстрый прогноз 89M (~30 секунд)
python final.py

# Анализ плотности парсинга
python gap_check.py
```
