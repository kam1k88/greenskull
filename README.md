# Метод локальных регрессий

## Суть

Метод Сергея — это **композит трёх локальных регрессий**. Каждая работает не на всей истории, а на **своей локальной окрестности** — и вместе они дают устойчивый прогноз.

Слово «локальные» здесь ключевое: каждая модель видит **не весь ряд**, а только ту его часть, где закономерность однородна.

## Три локальности

**M1 — локальная по времени.**
Окно последних 730 дней. Всё, что было раньше, отбрасывается — там другой режим роста, другая аудитория PostCrossing. Модель видит только свежий участок ряда.

**M2 — локальная по номерам уровней.**
Уровни 44–55 и 67–88. Белые (1–43) отбрасываются — другой масштаб. Красные (56–66) — ковид, аномальный режим. Модель видит только ту часть истории вех, где темп вёл себя «нормально».

**M3 — локальная по календарю.**
Та же выборка, но по датам, а не по номерам. Ловит локальные по времени года отклонения от среднего.

Каждая из трёх регрессий — **не глобальный фит по всей истории**, а локальная аппроксимация в своей окрестности.

## Почему это работает

Глобальная регрессия на нестационарных данных (весь ряд postcrossing с 2008) ловит **псевдотренды** и проваливается в переобучение. Локальная — работает только с той частью, где закономерность стабильна.

Три локальные регрессии покрывают **разные аспекты локальности**:

| Модель | Локальность | Что видит |
|---|---|---|
| M1 | по времени | свежая динамика роста |
| M2 | по номеру уровня | средний темп в нормальном режиме |
| M3 | по календарной дате | сезонные отклонения |

## Как объединяются

Локальные регрессии объединяются **взвешенным средним с динамическими весами**:

```
w₁ = 1/3 + 2/3 · p
w₂ = (1 − w₁) · 0.6
w₃ = (1 − w₁) · 0.4
```

где `p` — доля пройденного пути от вехи N к вехе N+1. То есть **веса тоже локальны** — они зависят от положения на пути:

- Далеко от цели — все три локальные оценки равноправны
- Близко к цели — доминирует M1 (локальная по свежему времени)

## Двойная локальность

Метод локальный **дважды**:

1. **По данным.** Каждая регрессия работает на своей подобласти (окно, диапазон уровней, календарь).
2. **По весам.** Вклад каждой регрессии зависит от текущего положения в прогнозе.

Это и есть «локальные регрессии» в чистом виде: не глобальная модель всего, а композит из нескольких локальных аппроксимаций, каждая — в своей зоне компетентности.

## Что даёт улучшение

Улучшения снимают **избыточную глобальность внутри локальных моделей**:

- Закрепление `q = 365.25` — убирает подгонку под изгиб окна (глобальный артефакт)
- K=4 вместо K=12 — сокращает число степеней свободы внутри M1
- `q₃ ∈ [300, 430]` — ограничивает M3 диапазоном, где локальность осмысленна
- Привязка M1 к последнему наблюдению — жёсткая локальная граница

Все четыре — не «больше модели», а «меньше глобальной свободы внутри локальной».

## Итог

**Метод Сергея = три локальные регрессии + динамическое взвешивание.**

Не «глобальная модель postcrossing», а **ансамбль локальных аппроксимаций**, каждая в своей подобласти данных, с весами, зависящими от положения в прогнозе.

Это устойчиво к нестационарности: не пытается описать весь ряд одной формулой, а берёт ту часть, где закономерность однородна.
